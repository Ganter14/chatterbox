# Оптимизация потокового вывода Multilingual TTS — Walkthrough

Мы успешно оптимизировали конвейер потокового вывода (streaming) для `ChatterboxMultilingualTTS`, достигнув показателя **RTF < 1.0** (Real-Time Factor) и улучшив структурную согласованность между потоковой и полной генерацией.

## Основные достижения

### 1. Производительность: RTF < 1.0
Мы достигли работы в реальном времени за счет внедрения нескольких ключевых оптимизаций в `S3GenStreamer`:
- **Кэширование промпта (Prompt Caching)**: Токены референсного голоса (промпт) теперь кодируются только один раз в начале потока. Это исключает избыточные вычисления $O(P)$ (где $P$ — длина промпта) на каждом чанке.
- **Скользящее окно (Sliding Window)**: Восстановлен механизм скользящего окна, что снижает вычислительную сложность с $O(N^2)$ до $O(N)$ для длинных фраз.
- **Синхронное выполнение**: Цикл стриминга переработан в синхронную модель, что устранило накладные расходы на многопоточность и обеспечило детерминизм.

### 2. Согласованность и точность
- **Фильтрация SOS/EOS**: Логика обработки токенов в `generate_streaming` приведена в соответствие с методом полной генерации `generate()`. Это гарантирует, что в вокодер попадают только речевые токены.
- **Управление состоянием вокодера**: Исправлено кэширование исходного сигнала (`last_s`) в вокодере HiFT. Это обеспечивает плавные переходы между чанками без щелчков и фазовых разрывов.
- **Выравнивание границ чанков**: Реализована обрезка lookahead (3 токена) в соответствии с требованиями модели Flow-Matching.

## Технические детали

### Логика `S3GenStreamer`
Стример теперь использует трехэтапный подход:
1. **Предварительное кодирование**: Кодирование токенов промпта один раз.
2. **Казуальное кодирование**: Кодирование только новых токенов каждого чанка.
3. **Скользящий декодер**: Передача промпта, накопленной истории (в пределах окна) и новых токенов в CFM-декодер.

### Обработка токенов
Мы явно фильтруем токены `SOS` и `EOS` внутри цикла стриминга, чтобы предотвратить попытки вокодера синтезировать тишину или артефакты завершения предложения в середине потока.

```python
# Из src/chatterbox/mtl_tts.py
# Фильтрация неречевых токенов для соответствия generate()
speech_tokens = [t for t in chunk_tokens[0] if t not in [self.s3gen.tokenizer.sos, self.s3gen.tokenizer.eos]]
```
