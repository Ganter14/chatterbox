# Реализация потокового вывода (Streaming) — Walkthrough

Мы успешно реализовали потоковый (streaming) вывод аудио для Chatterbox, обеспечив низкую задержку при сохранении всех преимуществ оптимизаций CUDA graphs.

## Выполненные изменения

### 1. Генераторы стриминга T3
В модель `T3` были добавлены методы `inference_stream` и `inference_turbo_stream`. Эти методы возвращают токены по одному по мере их генерации. Что критически важно, они интегрированы с существующей инфраструктурой `T3Graph` для использования CUDA graphs на шагах декодирования одиночных токенов.

### 2. S3GenStreamer
Был реализован новый класс `S3GenStreamer` для управления состоянием стриминга на этапе преобразования токенов в аудио. Он использует подход накопленного декодирования со скользящим окном для обеспечения непрерывности аудио и предотвращения артефактов на границах чанков (щелчков/помех). Класс корректно обрабатывает требование lookahead в 3 токена, необходимое для модели flow-matching.

### 3. Расширение API TTS
Все высокоуровневые классы TTS теперь предоставляют метод `generate_streaming`:
- `ChatterboxTTS.generate_streaming`
- `ChatterboxTurboTTS.generate_streaming`
- `ChatterboxMultilingualTTS.generate_streaming`

Эти методы возвращают кортежи `(audio_chunk, sample_rate, timing_metadata)`.

### 4. Верификация и бенчмаркинг
- **Регрессия**: В `verify_regression.py` добавлена проверка согласованности, гарантирующая, что склеенные чанки стриминга совпадают с результатом полной генерации (MSE < 1e-8).
- **Производительность**: Скрипт `benchmark_cuda.py` был обновлен для измерения времени до первого чанка (Time To First Chunk, TTFC).

## Результаты валидации

### Сравнение производительности

| Модель | Ускорение (vs Base) | TTFC (Оптимизировано) |
| :--- | :--- | :--- |
| **Chatterbox-Turbo (EN)** | **1.89x** | **405.84 ms** |
| **Chatterbox-Multilingual (RU)** | **2.32x** | **1079.16 ms** |

### Согласованность
Потоковый вывод практически идентичен обычному выводу, что подтверждено проверками в `verify_regression.py`.

## Как запустить
Вы можете протестировать новую функциональность стриминга с помощью предоставленного примера:
```bash
python example_streaming.py --text "Привет, это проверка новой системы потокового вывода." --use_cuda_graph
```
*(Примечание: требуется библиотека `sounddevice` для воспроизведения)*
